# UniHelper — приложение + утренняя сводка в Telegram

## Что внутри

- `index.html` — само приложение.
- `netlify/functions/sync.mjs` — принимает от приложения расписание и срочные задачи, проверяет подпись Telegram.
- `netlify/functions/morning.mjs` — запускается каждый час и в 7:00 по времени пользователя шлёт сводку.
- `netlify/lib/` — общий код: проверка подписи, отправка сообщений, текст сводки.

## Как залить

Перетаскиванием (Netlify Drop) функции не публикуются, поэтому сайт нужно подключить к GitHub — так же, как приложение для зала.

1. **GitHub.** Создайте новый репозиторий, например `uni-helper`. На странице репозитория нажмите «uploading an existing file» и перетащите **всё содержимое этой папки**, сохранив папку `netlify` со вложенными папками. Нажмите Commit.
2. **Netlify.** Откройте текущий сайт приложения → **Site configuration → Build & deploy → Continuous deployment → Link repository** → выберите `uni-helper`. Build command оставьте пустым, Publish directory — `.`. Адрес сайта не изменится, в BotFather ничего менять не нужно.
3. **Токен бота.** **Site configuration → Environment variables → Add a variable**: имя `BOT_TOKEN`, значение — токен вашего бота из @BotFather. Затем **Deploys → Trigger deploy → Deploy site**.
4. **Проверка.** Откройте приложение из Telegram, прокрутите вниз до блока «Утренняя сводка» и нажмите «Прислать сводку сейчас для проверки». Бот должен прислать сообщение.

Дальше обновления идут через GitHub: заменили `index.html` в репозитории — Netlify пересоберёт сайт сам.

## Если не пришло

- **«На сервере не задан BOT_TOKEN»** — пропущен шаг 3 или не сделан повторный деплой.
- **«Подпись Telegram не прошла проверку»** — в `BOT_TOKEN` токен другого бота. Нужен токен того бота, который открывает приложение.
- **«bot can't initiate conversation»** — напишите боту /start.
- **Кнопка ничего не делает / «Сервер ответил не так…»** — функции не опубликовались. Проверьте, что в репозитории есть папка `netlify/functions`.
- Журнал утренних запусков: **Logs → Functions → morning**.

## Как это работает

После каждого изменения приложение отправляет на сервер короткую выжимку: предметы, будущие пары и заголовки невыполненных задач из квадранта «Срочно и важно». Заметки к предметам, подробности задач и остальные квадранты на сервер не уходят.

Раз в час сервер проверяет, у кого наступило 7 утра, и присылает: во сколько первая пара, сколько всего пар и до скольки, плюс список срочных и важных задач. Сводка приходит только в дни, когда есть пары. В дни без пар бот молчит, даже если есть срочные задачи. Выключить сводку можно переключателем в приложении.
